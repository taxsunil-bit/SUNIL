# 🚀 Code Learning & Practice App

An interactive web application for learning and practicing coding concepts through quizzes and hands-on exercises.

## ✨ Features

### 📚 Interactive Quiz System
- **Multiple Categories**: JavaScript, Python, Algorithms, and Data Structures
- **Code Examples**: Real code snippets with each question
- **Instant Feedback**: Learn from detailed explanations
- **Progress Tracking**: Visual progress bar and score tracking
- **Keyboard Shortcuts**: Use number keys (1-4) to select answers, arrow keys to navigate

### 💻 Live Code Editor
- **Practice Coding**: Write and execute JavaScript code in the browser
- **Instant Results**: See output immediately
- **Error Handling**: Clear error messages for debugging
- **Keyboard Shortcut**: Ctrl+Enter to run code

### 📖 Learning Resources
- Curated learning topics for each category
- Structured curriculum guides
- Best practices and tips

## 🚀 Getting Started

### Quick Start
Simply open `index.html` in your web browser to start learning!

```bash
# Clone the repository (if not already done)
git clone https://github.com/taxsunil-bit/SUNIL.git

# Navigate to the directory
cd SUNIL

# Open in browser
# - Double-click index.html, OR
# - Right-click index.html and choose "Open with Browser", OR
# - Use a local server (recommended):
python -m http.server 8000
# Then visit: http://localhost:8000
```

## 📋 How to Use

### Taking Quizzes
1. **Select a Category**: Choose from JavaScript, Python, Algorithms, or Data Structures
2. **Answer Questions**: Click on your answer choice or use number keys (1-4)
3. **Get Feedback**: Receive instant feedback with explanations
4. **Navigate**: Use Previous/Next buttons or arrow keys
5. **View Score**: Complete all questions to see your final score

### Using the Code Editor
1. **Write Code**: Type or paste your JavaScript code in the editor
2. **Run Code**: Click the "▶ Run Code" button or press Ctrl+Enter
3. **View Output**: See the results in the output panel below
4. **Debug**: Error messages will appear if there are issues
